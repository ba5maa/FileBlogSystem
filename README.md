# FileBlogSystem

Working Features

User Authentication:
- Login and Signup: Users can create new accounts and log in to existing ones.
- Session Management: Handles saving and loading authentication data, and automatically clears expired sessions.
- Authenticated API Requests: Ensures all sensitive operations are performed with valid user authentication.

Content Management:
- Post Creation: Users can create new blog posts with titles, content, categories, and tags.
- Image Uploads: Supports uploading images with posts using Base64 encoding.
- Post Status: Allows posts to be saved as drafts, published immediately, or scheduled for a future date and time.
- Post Editing: Users can edit their existing posts, including content, categories, tags, and images.
- Post Deletion: Functionality to delete posts.

Post Interaction:
- View Posts: Displays a feed of recent posts and a draft feed of the user's own posts and drafts for edits.
- Search and Filter Posts: Users can search posts by keywords and filter by tags.
- Post Liking: Users can like and unlike posts.

Commenting System:
- View comments on posts.
- Add new comments to posts.

Drafts Management:
- Users can view and manage their draft posts.
- Option to publish drafts or cancel scheduled posts.

Admin Panel:
- Admins can delete a certain user or make them an admin.
- Admins can create or edit a category or tag.

Edit Profile:
- Users can edit their profile picture, username or emails.
- Users can change their passwords.
